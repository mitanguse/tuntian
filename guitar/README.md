# 拾光吉他 · 练琴助手

零依赖纯前端网页（HTML + CSS + JS），不需要安装、不需要服务器后端。
打开浏览器就能用，手机也能用（同一 WiFi 下）。

## 启动

双击 `start.bat`，会自动开浏览器。
或者手动：在这个目录执行 `python -m http.server 8123 --bind 0.0.0.0`，然后打开 <http://127.0.0.1:8123/>

> 麦克风必须在 `http://` 或 `https://` 下才能授权，直接双击 `index.html`（file://）用不了麦克风。

## 五个模块

| 模块 | 做什么 |
| --- | --- |
| 调音 | 六根弦标准音（E2 A2 D3 G3 B3 E4），指针 + 音分显示，自动认弦，偏了会告诉你往紧还是往松拧 |
| 曲谱 | 8 首单音旋律（六线 TAB + 品位数）+ 12 首弹唱谱（和弦进行 + 节奏型），可听示范、可跟练打分 |
| 和弦 | 16 个常用和弦指法图，按「逐弦检查」一根一根拨，逐弦验音准 |
| 节奏 | 40–160 BPM 节拍器，4/4 · 3/4 · 2/4，四分 / 八分 / 十六分细分 |
| 进度 | 通过曲目、按对的和弦、连续天数、五个关卡的解锁状态（存在浏览器本地） |

## 跟练怎么打分

- 单音旋律：麦克风实时做音高检测（自相关算法），每个音符在它的时间窗内被弹对就记一次命中，最后算准确率。≥60% 记为通过。
- 弹唱谱：用能量包络做起音检测，判断每个小节有没有扫下去，给「完成度」。
- 和弦：不是同时判六根弦（浏览器做不到），而是引导你一根一根拨，逐弦验音高。

## 已知边界

- 和弦扫弦只能判「有没有弹、有没有踩在小节上」，判不了六根弦各自准不准。
- 环境吵闹、用音箱外放会产生误判，戴耳机或安静房间最准。
- 曲谱是教学简化版，个别地方与原版有出入，以原曲为准。
