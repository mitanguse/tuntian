屯 田

三国题材 · 卡牌堆叠 · 生存经营  |  设计说明

把《堆叠大陆》的「拖动即合成」搬进三国：你是一个村子的主事者，靠堆叠把人和资源捏成兵，边屯田边扛住十天的兵灾。

一、核心循环

采集→合成→屯粮→扩军→御敌→卖钱→开包→新配方

一圈约 40 秒，正好是一天。玩家的每个动作都能在当天结算里看到后果：少收一次粮，晚上就有人跑。

二、三个留住玩家的钩子

  • 配方发现：8 条配方，合成一次点亮一条。图鉴里的 ？？？就是玩家的下一步目标。
  • 危机递进：第 3 / 5 / 7 / 9 天各来一波，强度阶梯上升，逼玩家在「多屯粮」和「多造兵」之间做取舍。
  • 明确终点：守满 10 天即胜，一局约 6 分钟。有终点的循环才有人愿意再来一局。

三、机制与题材的映射

堆叠大陆屯田
村民村民（既是劳动力也是兵源）
食物粮草（按人头每天消耗）
木头 / 石头森林采出树木 / 石头，两张劈开才是木材 / 石料
卖卡换钱市集卖粮卖料
卡包招募令 / 锦囊
怪物山贼 → 黄巾 → 敌军

四、设计取舍

1. 一次拖放只加工一次。早期版本允许连锁合成，结果一拖就把一村人全变成兵，玩家还没反应过来就断粮了。改成单次结算后，每个动作都是玩家自己的决定。

2. 产出单独成堆。产出如果留在原料堆里，村民、农田、粮草会叠成一张看不见的牌。分离之后「农民 + 农田」始终留在桌上，再拖一次就是再收一季粮。

3. 敌人优先打血最厚的。随机打人会让村民毫无理由地暴毙，改成打前排后，玩家能通过「先造兵」主动保护劳动力，死亡变得可归因。

4. 人口即压力。每个单位每天吃 1 粮草，所以扩军不是免费的：兵越多，粮越紧，田也越多。这条约束把「造兵」和「屯田」绑成了一个真实的取舍。

5. 合成要有过程，不能瞬间完成。一拖就出卡的话，玩家来不及确认自己干了什么，也容易连点刷资源。现在合成要 0.6 秒：牌堆发光、底部打出「伐木中」的标签，到点才产卡，产出的牌再弹一下。这 0.6 秒既是反馈，也是天然的频率限制。

6. 允许拆堆，而不是禁止混放。玩家一定会把牌拖错地方，混出来的堆如果拆不开，就成了死牌。所以轻点牌堆（或长按 0.35 秒）会拆出最上面一张，落到旁边空位。规则允许犯错，但必须给退路。

7. 单局要能随时暂停。浏览器里玩的游戏，玩家随时会被叫走。暂停冻住的不只是倒计时，还有拖拽和开包；切到别的标签页也会自动暂停，回来不会发现村子已经饿死一半。

8. 敌人会自己动，压力才是真的。如果敌人只是站着等玩家来打，那它就是一个待领的奖励。现在贼寇刷出来后一点点爬向最近的村民，贴上就咬；玩家看到它出发，才真的会去造兵、去拦截。战斗仍然只由玩家发起（把兵拖到敌人身上），所以不会出现「手一滑村民自己冲上去送死」的挫败——压力来自时间，不来自失控。

五、数值骨架

单位血攻定位
村民20劳动力，不能打
民兵31临时征召，比士兵弱
士兵52基础战力
枪兵 / 弓兵6 / 53 / 3进阶，弓兵先手
铁枪兵 / 强弓手9 / 85 / 5终局战力

敌人按「4/2 → 7/3 → 12/5」递进，对应玩家第 3、7、9 天应有的兵力上限。贼寇每 1.2 秒向村民挪 62px，贴到 130px 内每 1.5 秒咬 1 血——村民 2 血，也就是被贴上后约 3 秒内不救就会死人，给的是「还来得及」的紧张感。

v1.1 起敌人不再凭空出现在牌堆中间：每波都有固定来向，从东 / 南 / 西 / 北的桌边排队进场，沿直线压向村中心；顶栏提前一天报「明日：山贼×2 · 东面」，到了当天改报「在场」。玩家把兵摆在来路上，敌人的前进方向上就会被挡住（判定是「在正前方 118px 内、偏离路线 64px 内」），挡路只能拖时间、不能消灭，还得把兵拖上去开打——于是「守哪条路、留多少兵机动」变成每天都要重算的取舍。

每逢偶数天开头抽一张事件卡（旱灾 / 流民 / 招降 / 疫病），两个选项一好一坏、都要付本钱：挖井 6 钱换粮草无损，硬扛粮草折半；收留流民耗 4 粮换 1 个村民；收编山贼 8 钱换 1 个民兵。事件把「钱、粮、人」三种资源来回兑换，正好卡在人手最紧的节点上。结算按 人口×4 + 总战力×5 + 总血量 + 存粮×2 + 铜钱×0.5 打分，120 / 85 / 55 分依次为 S / A / B，其余 C。

六、迭代记录

  • v0.1 骨架：拖拽、堆叠、配方、金币
  • v0.2 加天循环、断粮、敌人波次、结算页
  • v0.3 修三处体验问题：连锁合成失控、产出堆叠不可见、敌人随机索敌
  • v0.4 加图鉴计数、数量角标、手机端适配
  • v0.5 合成加入 0.6 秒制作过程（发光 + 进度标签 + 产出弹入），并修正卡面异体字
  • v0.6 轻点 / 长按拆出一张，解决混堆拆不开的死牌问题
  • v0.7 加暂停（顶栏按钮 / 空格，切后台自动暂停），暂停时时间、拖拽、开包全部冻结
  • v0.8 加「森林」采集点；新增民兵线：村民 + 木材 → 民兵，民兵 + 石料 → 士兵；手机开局改 3×3 网格，卡片底部数值压紧不再被裁
  • v0.9 资源改成两段加工：森林采出树木 / 石头（森林不消失），两张树木劈成木材、两张石头碎成石料（也可以派村民砍 / 采，二选一）；贼寇改成主动扑向村民，贴身就咬，玩家必须及时把兵拖上去
  • v1.0 人手变成硬约束：村民下地、进林、伐木、采石之后当天就「疲」（卡面变灰 + 左上角标），次日恢复；干过活的村民不能再拿去合成或编入军队。顶栏新增「人手 x/y」，开局 3 个村民，每天第一步就得想清楚：谁去种粮、谁去采木、谁把力气留给当兵
  • v1.1 威胁有了预告和来路：敌人从四边之一成队进场、沿路线压向村中心，兵摆在路上就能挡住（但挡不死，仍要派兵去打）；顶栏常驻「明日 / N 天后 · 敌方构成 · 来向」；每逢偶数天弹事件卡二选一（旱灾 / 流民 / 招降 / 疫病）；结算新增 S/A/B/C 评级（人口、兵力、血量、存粮、铜钱加权）

七、技术

原生 HTML / CSS / JavaScript，零依赖，单页加载。卡牌用 DOM + Pointer Events 实现鼠标与触屏统一的拖拽，不引物理引擎以保证稳定性；全部数值集中在 data.js，调平衡不碰逻辑。
