# 屯田 · 三国堆叠

一个用「拖动即合成」做的三国题材卡牌经营原型。你是一个村子的主事者，靠堆叠把人和资源捏成兵，边屯田边扛住十天的兵灾。

## 玩法

- **拖动**卡牌叠在一起，凑齐配方自动加工
- 每个村民每天要吃 1 份粮草，断粮会跑人
- 资源拖进右下角**市集**卖钱，铜钱买卡包
- 守满 **10 天** 获胜，敌人会一波比一波强

## 运行

纯静态页面，无依赖、无构建：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

也可以直接双击 `index.html`。

## 文件结构

| 文件 | 作用 |
|------|------|
| `index.html` | 页面骨架与 UI |
| `style.css` | 卡牌视觉、动效、响应式 |
| `data.js` | 卡牌表、配方表、卡包、波次（**调平衡只改这里**） |
| `game.js` | 拖拽、堆叠、合成、天循环、战斗 |
| `about.html` | 设计说明（机制、取舍、迭代记录） |

## 设计

核心循环：采集 → 合成 → 屯粮 → 扩军 → 御敌 → 卖钱 → 开包 → 新配方。

详细设计思路见 [`about.html`](about.html)。
